# Learning Express REST API

A small coursework exercise to understand how REST APIs
work using Node.js and Express.js.

## Concepts explored
- Creating an Express server
- Handling GET, POST, and DELETE requests
- Working with route parameters
- Reading JSON request bodies
- Managing data using a JavaScript array
- Testing endpoints using Postman
- Basic error handling and HTTP status codes
- Handling missing books (404 Not Found)
- Validating request data (400 Bad Request)
- Handling invalid or missing book IDs

## Run locally
npm install
node server.js
